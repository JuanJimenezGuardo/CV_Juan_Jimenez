# CV de Juan Jimenez

Curriculum vitae en LaTeX, preparado para lectura humana y sistemas ATS.

## Perfil

El documento presenta un perfil hibrido que conecta dos dimensiones:

| Ingenieria | Negocio |
| --- | --- |
| Procesos, calidad, indicadores y mejora continua | Planeacion, costos, proyectos y generacion de valor |

La propuesta evita separar la experiencia tecnica de la capacidad para entender y resolver necesidades del negocio.

## Archivos

- `CV_Juan_Jimenez.tex`: fuente editable del CV.
- `.gitignore`: excluye archivos auxiliares generados por LaTeX.

## Compilacion

Con una distribucion LaTeX instalada, ejecuta:

```bash
pdflatex CV_Juan_Jimenez.tex
```

Antes de enviar el CV, reemplaza los campos entre corchetes con los datos definitivos y revisa que cada logro incluya un resultado concreto cuando sea posible.
